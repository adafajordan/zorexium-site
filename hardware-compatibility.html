Hardware Compatibility

Verify hardware compatibility with Zorexium Labs

Compatibility Overview

Zorexium Labs hardware is compatible with most modern systems. Use this guide to ensure your setup meets compatibility requirements.

System Requirements

  • Operating System: Windows 10+, macOS 10.14+, Linux 4.4+
  • RAM: Minimum 4GB (8GB recommended)
  • Storage: 2GB free space
  • Power: USB 3.0 connection or direct power supply

Supported Hardware

Processors

Intel Core i5+, AMD Ryzen 5+, Apple Silicon (M1/M2/M3)

Graphics

NVIDIA GTX 960+, AMD Radeon RX 470+, Integrated graphics supported

Storage

SSD or HDD with USB 3.0+ interface

Peripherals

USB 3.0/3.1 devices, external hard drives, flash drives, displays (4K supported)

Known Issues

  • USB 2.0 devices may have reduced compatibility
  • Some older graphics cards require driver updates
  • Windows 7 and earlier versions not supported
  • Virtual machines may have limited hardware access

Troubleshooting

Device Not Recognized

Update your device drivers and ensure USB ports are not powered off in BIOS/UEFI settings.

Slow Performance

Check USB connection type - ensure USB 3.0+ for optimal speeds. Move device to different port if speed is low.

Connection Issues

Try a different USB cable, disable power saving features, or restart your system.

Driver Installation

Most hardware automatically installs drivers. If needed, download platform-specific drivers from the product support page.
